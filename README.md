# Apache Spark Restaurant Revenue Forecasting

Restaurant revenue prediction using Java, Apache Spark MLlib, and MongoDB.

## Overview

This project compares three regression approaches:

- Linear Regression
- Random Forest Regression
- Gradient-Boosted Trees (GBT)

## Features

- MongoDB data ingestion
- Apache Spark DataFrames
- Data cleaning and preprocessing
- Feature engineering
- Categorical feature encoding
- Basic hyperparameter tuning
- Model comparison using RMSE, MAPE, and R²
- Prediction output to MongoDB and CSV

## Technologies

Java | Apache Spark | Spark MLlib | MongoDB | Maven | Machine Learning

## Project Flow

MongoDB → Apache Spark → Preprocessing → Feature Engineering → Regression Models → Evaluation → Revenue Prediction
